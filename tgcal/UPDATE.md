# Обновление до версии 3

Ваш проект: `D:\Bot Calendar\The App\tg_calendar`. По списку файлов в вашем RAR: в корне лежит версия 2.0 (рабочая), а внутри неё
папка `tgcal\` с более новой версией, которую вы распаковали, но не скопировали поверх. Эта инструкция переносит всё на версию 3.
Файл `.env` в архиве нет, он не пострадает.

## 0. Страховка (1 минута)
Скопируйте папку `tg_calendar` целиком в `tg_calendar_backup` (Проводник → копировать/вставить). Без `.git`, если он очень большой, тоже можно.

## 1. Файлы
1. Распакуйте новый `tgcal.zip` в любую временную папку, например `D:\Temp\new`. Получится `D:\Temp\new\tgcal\...`.
2. Откройте PowerShell в папке проекта и выполните:
   ```
   cd "D:\Bot Calendar\The App\tg_calendar"
   robocopy "D:\Temp\new\tgcal" . /E
   ```
   Новые файлы встанут на места, старые заменятся. `.env` не затрагивается.
3. Старую вложенную папку `tgcal` внутри проекта больше не используйте. Удалите её, чтобы не путаться:
   ```
   Remove-Item -Recurse -Force .\tgcal
   ```
4. Проверьте, что в корне есть `docs`, `supabase`, `scripts`, `.gitignore`, `.env`, и что нет вложенной `tgcal`:
   ```
   dir -Force
   ```

## 2. База данных (Supabase → SQL Editor)
Выполните по очереди файлы из `supabase\migrations`: `002_v2.sql`, `003_v21.sql`, `004_v3.sql`. Каждый: открыть файл, скопировать всё, вставить в SQL Editor, Run. Файлы можно запускать повторно, ошибок это не вызовет. Если 002 вы уже выполняли, он пройдёт без изменений.

## 3. Функции
```
npx supabase functions deploy bot api cron google ics --use-api
```

## 4. Команды бота
```
powershell -ExecutionPolicy Bypass -File .\scripts\setup-bot.ps1 -ProjectRef ujvcphbwygjfefwuzgsu
```

## 5. Сайт (мини-приложение)
GitHub Desktop → проверьте список изменений (файла `.env` там быть не должно) → Commit to main → Push origin. Через минуту страница обновится. Закройте и снова откройте приложение в Telegram.

## 6. Планировщик
Если ещё не запускали `supabase\cron.sql`, сделайте это (подставьте ref и CRON_SECRET). Проверка: бот → `/stats`.

## 7. Проверка
- Откройте приложение: появится обучение. Его можно пройти заново: Настройки → «Обучение».
- Настройки → «Язык»: выберите язык, интерфейс переключится. В боте: `/lang`.
- Напишите боту: `запиши Анна маникюр завтра в 15:00 +998901234567`. В карточке появится клиент и кнопка «Заготовка клиенту». Карточку клиента покажет `/client +998901234567`.
- `/ref` покажет вашу реферальную ссылку, она же есть в Настройки → Тариф.

## 7а. Что нового в 3.1
Появился файл `docs/boot.js` (тема применяется до отрисовки, без «мигания»), настройки стали меню с подстраницами, подписки скрыты за плашкой «Подписки», новые выбор времени (циферблат) и даты (барабаны), кнопка языка в шапке, исправлен вход в Google. Если после обновления что-то не открывается, проверьте, что `boot.js`, `i18n.js`, `app.js` лежат в `docs` и загружены на GitHub.

## 7б. Что нового в 3.2
Быстрее запись (запросы идут одновременно, Google обновляется после ответа), события из бота появляются в приложении сами (при возврате в приложение и раз в 30 секунд), команда «напомни» уведомляет в сам момент. Обновление как обычно: файлы, `functions deploy`, Commit и Push сайта. Новых SQL-миграций нет.

## 7в. Версия 3.3 (безопасность и хранение)
В SQL Editor выполните `supabase\migrations\005_safety.sql` (после 002, 003 и 004). Затем `functions deploy` и Commit и Push сайта. Опционально можно задать секреты `MAX_GROUP_MEMBERS` (по умолчанию 300) и `DB_LIMIT_MB` (по умолчанию 500).

## 8. Google (если ещё не работает)
1. В `.env` допишите `GOOGLE_CLIENT_ID=...` и `GOOGLE_CLIENT_SECRET=...` (шаг 8 из README: Google Cloud → Calendar API → OAuth → Web application).
2. Redirect URI в консоли Google: `https://ujvcphbwygjfefwuzgsu.supabase.co/functions/v1/google`.
3. Добавьте свою почту в Test users (режим Testing).
4. `npx supabase secrets set --env-file .env`, затем снова `npx supabase functions deploy bot api cron google ics --use-api`.
5. Приложение → Настройки → «Админ-панель» → блок «Google: проверка настройки»: там видно, что задано, и точный Redirect URI. При ошибке подключения приложение теперь показывает причину от Google. Пришлите её, если не заработает.
